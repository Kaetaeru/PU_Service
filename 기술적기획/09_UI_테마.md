# 09. UI 테마

> 기준: 기존 데모 `ems-request.html` (손님 요청 폼), `ems-admin.html` (호스트 확인 화면)
> 목적: StayOps의 세 화면(손님 신청 폼 / 배차 응답 웹 / 호스트 운영 화면)을 하나의 시각 언어로 만든다.

---

## 1. 기준 결정

기존 데모 두 개가 이미 완성된 디자인 시스템을 갖고 있다. **이것을 StayOps 표준으로 삼는다.**

데모는 EMS 배송대행 서비스지만 화면 구조가 StayOps에 필요한 것과 같다.

| 데모 | StayOps 대응 |
|---|---|
| `ems-request.html` — 손님 요청 폼, 다국어, 하단 고정 제출, 결과 카드 | 손님 신청 폼 |
| `ems-admin.html` — 호스트 확인, 입력 + 요약 박스 + 기록 테이블 | 호스트 운영 화면 |

### `pickup_2.html`과의 관계

현재 픽업 폼은 같은 계열이지만 세부가 다르다.

| | 데모 (`ems-*`) | 현재 폼 (`pickup_2.html`) |
|---|---|---|
| 브랜드 그린 | `#2F6B52` | `#2f5d43` |
| 종이색 | `#FBFAF6` | `#fbfaf5` |
| 잉크 | `#22312B` | `#1d2b21` |
| 본문 서체 | Gowun Dodum | Inter |
| 제목 서체 | Fraunces | Instrument Serif |
| 보조 서체 | — | JetBrains Mono |
| 상단 모티프 | 항공우편 줄무늬 | 티켓 스텁 (절취선) |

색은 사실상 같은 계열이고 서체와 모티프만 다르다. **데모 쪽으로 통일한다.** 서체를 한글 친화적인 Gowun Dodum으로 맞추면 다국어 폼에서 한국어·중국어·영어가 함께 나와도 무너지지 않는다.

`pickup_2.html`의 티켓 스텁 절취선은 이동 서비스와 잘 맞으므로, 손님 폼 헤더에 한해 항공우편 줄무늬 대신 쓸 수 있다. 색과 서체는 데모 기준을 따른다.

## 2. 색

```css
:root{
  --paper:#FBFAF6;      /* 배경. 크림 종이 */
  --card:#FFFFFF;       /* 카드 면 */
  --ink:#22312B;        /* 본문 글자. 짙은 녹회색 */
  --muted:#7B867F;      /* 보조 설명, 라벨 힌트 */
  --line:#E4E2DA;       /* 테두리, 구분선 */

  --leaf:#2F6B52;       /* 브랜드 그린. 강조·주요 버튼·포커스 */
  --leaf-soft:#E4F0E8;  /* 그린 배경 (태그, 요약 박스, 보조 버튼) */

  --mail-red:#D64545;   /* 오류, 필수 표시, 삭제 */
  --mail-blue:#3457A6;  /* 항공우편 줄무늬에만 사용 */

  --gold:#B9872E;       /* 금액·정산 강조 */
  --gold-soft:#F7EEDC;  /* 금액 박스 배경 */
}
```

`--leaf`는 브랜드별로 덮어쓸 수 있게 둔다. 데모가 이미 그렇게 설계돼 있고, 호스트별 브랜딩을 붙일 때 이 변수 하나만 바꾸면 된다.

검정(`#000`)과 순백 배경은 쓰지 않는다. 종이 느낌이 이 디자인의 성격이다.

## 3. 서체

```html
<link href="https://fonts.googleapis.com/css2?family=Gowun+Dodum&family=Fraunces:opsz,wght@9..144,600;9..144,700&display=swap" rel="stylesheet">
```

```css
body { font-family:'Gowun Dodum','Noto Sans SC','Noto Sans KR',sans-serif; line-height:1.55; }
h1, .brand { font-family:'Fraunces',serif; }
```

- 본문·입력·버튼: **Gowun Dodum**
- 브랜드명·제목: **Fraunces** (serif)
- `.brand`는 15px / `letter-spacing:.14em` / 대문자 / `--leaf`
- `h1`은 26~27px / 700

입력 필드 글자 크기는 **16px 이상**을 지킨다. 그 아래로 내려가면 iOS 사파리가 포커스 시 화면을 확대한다.

## 4. 레이아웃

```css
.wrap{ max-width:560px; margin:0 auto; padding:0 18px }   /* 손님 폼 */
.wrap{ max-width:620px; margin:0 auto; padding:0 18px }   /* 호스트 화면 */
```

모바일 우선. 375px에서 정상 동작해야 한다.

상단 장식 띠는 10px 높이로 페이지 맨 위에 둔다.

```css
.airmail{
  height:10px;
  background:repeating-linear-gradient(-45deg,
    var(--mail-red) 0 14px, #fff 14px 28px,
    var(--mail-blue) 28px 42px, #fff 42px 56px);
}
```

## 5. 구성 요소

### 카드 (section)

```css
section{
  background:var(--card);
  border:1.5px solid var(--line);
  border-radius:14px;
  padding:20px 18px;
  margin-top:16px;
}
```

테두리는 전부 **1.5px**다. 1px도 2px도 쓰지 않는다.

### 섹션 태그

```css
.sec-tag{
  display:inline-block; font-size:12px; letter-spacing:.1em;
  color:var(--leaf); background:var(--leaf-soft);
  border-radius:99px; padding:3px 12px; margin-bottom:14px;
}
.sec-tag.gold{ color:var(--gold); background:var(--gold-soft) }
```

### 라벨과 입력

```css
label{ display:block; font-size:14px; font-weight:600; margin:16px 0 5px }
label .req{ color:var(--mail-red) }
label .hint{ display:block; font-weight:400; color:var(--muted); font-size:12.5px }

input,select,textarea{
  width:100%; padding:11px 12px; font-size:16px;
  font-family:inherit; color:var(--ink);
  border:1.5px solid var(--line); border-radius:10px; background:#fff;
}
input:focus,select:focus,textarea:focus{
  outline:2px solid var(--leaf); outline-offset:1px; border-color:var(--leaf);
}
```

필수 항목은 라벨에 빨간 표시, 설명은 라벨 안 `.hint`로 넣는다. 별도 안내 문단을 만들지 않는다.

### 가로 배치

```css
.row2{ display:flex; gap:10px }
.row2>div{ flex:1 }

.phone-row{ display:flex; gap:8px }
.phone-row .cc{ width:92px; flex:none }   /* 국가번호 */
```

`.phone-row`는 국가번호 + 번호 조합이다. **손님 WhatsApp 번호와 기사 전화번호 입력에 그대로 쓴다.**

### 버튼

```css
button.primary{
  width:100%; padding:14px; font-size:16px; font-family:inherit;
  background:var(--leaf); color:#fff; border:none; border-radius:12px;
}
button.ghost{
  width:100%; padding:12px; font-size:15px; font-family:inherit;
  background:var(--leaf-soft); color:var(--leaf);
  border:1.5px dashed var(--leaf); border-radius:10px;
}
button:active{ transform:translateY(1px) }
```

주 버튼은 채운 그린, 보조 버튼은 점선 테두리 + 연한 그린 배경이다.

### 하단 고정 제출 (손님 폼)

```css
.go{
  position:fixed; left:0; right:0; bottom:0;
  padding:14px 18px calc(14px + env(safe-area-inset-bottom));
  background:linear-gradient(to top,var(--paper) 70%,transparent);
}
.go button{
  display:block; max-width:524px; margin:0 auto; width:100%;
  padding:15px; font-size:17px;
  background:var(--leaf); color:#fff; border:none; border-radius:12px;
  box-shadow:0 4px 14px rgba(0,0,0,.18);
}
```

`body`에 `padding-bottom:120px`을 줘서 고정 버튼에 내용이 가리지 않게 한다. `env(safe-area-inset-bottom)`으로 아이폰 홈 인디케이터를 피한다.

### 결과 카드 (stamp)

```css
.stamp{ border:1.5px solid var(--line); border-radius:14px; overflow:hidden; background:var(--card) }
.stamp .head{
  display:flex; justify-content:space-between; align-items:center;
  padding:12px 16px; border-bottom:1.5px solid var(--line);
  background:var(--leaf-soft);
}
.stamp .copy{
  border:1.5px solid var(--leaf); background:#fff; color:var(--leaf);
  border-radius:99px; padding:5px 14px; font-size:13px;
}
.stamp .copy.done{ background:var(--leaf); color:#fff }
.stamp pre{ padding:14px 16px; font-size:13.5px; line-height:1.7; white-space:pre-wrap }
```

제출 후 확인 화면에 쓴다. 복사 버튼을 누르면 `.done`으로 상태가 바뀐다.

### 금액 박스

```css
.bill{ border:1.5px solid var(--gold); border-radius:12px; overflow:hidden; background:var(--gold-soft) }
.bill .line{ display:flex; justify-content:space-between; padding:10px 16px; font-size:14.5px }
.bill .line+.line{ border-top:1px dashed rgba(185,135,46,.4) }
.bill .line.total{ background:var(--gold); color:#fff; font-weight:700; font-size:16px }
```

금액만 골드 계열로 분리한다. 항목별 한 줄씩 쌓고 합계는 채운 골드로 마감한다.

**손님 신청 폼에는 이 컴포넌트를 쓰지 않는다.** 금액 박스는 Host 운영 화면과 배차 응답 Web에서만 쓴다 (`08_요금표.md` §1.1). 합계 줄에는 세금포함 총액을 넣는다.

### 오류

```css
.err{
  display:none; margin-top:14px; padding:12px 14px;
  border:1.5px solid var(--mail-red); border-radius:10px;
  color:var(--mail-red); font-size:14px; background:#FDF1F1;
}
.err.show{ display:block }
```

서버 검증 오류는 이 박스로 보여준다. 필드별 오류는 해당 입력 아래에 붙일 수 있게 설계한다.

### 표 (호스트 화면)

```css
table{ width:100%; border-collapse:collapse; font-size:13px }
th,td{ padding:8px 6px; border-bottom:1px solid var(--line); text-align:left; vertical-align:top }
th{ color:var(--muted); font-weight:600; font-size:12px }
```

### 다국어 토글

```css
.langs{ display:flex; gap:8px }
.langs button{
  flex:1; padding:9px 0; font-size:14px;
  border:1.5px solid var(--line); border-radius:99px;
  background:var(--card); color:var(--muted);
}
.langs button.on{ border-color:var(--leaf); background:var(--leaf); color:#fff }
```

손님 폼 상단에 둔다. EN / KO / CN.

## 6. 화면별 적용

### 손님 신청 폼

`ems-request.html` 구조를 그대로 따른다.

```text
airmail 띠
brand + h1 + sub
언어 토글
[손님 정보]      이름 · WhatsApp 번호(국가번호) · 언어 · 수신 동의
[이동]           픽업/드랍오프 · 날짜 · 시간 · 항공편
[노선]           거점 · 터미널 · 숙소
[인원과 짐]      인원 · 대형수하물
[옵션]           카시트(+연령 메모) · 터미널 경유 · 특이사항
하단 고정 [신청하기]
    ↓ 제출 후
결과 stamp 카드 (예약 참조번호 + 요약)
```

**금액을 절대 표시하지 않는다.** `.bill` 컴포넌트를 쓰지 않고, 어떤 항목 옆에도 가격을 붙이지 않으며, 옵션을 켜고 끌 때 금액 변동이 보이지 않는다. 결과 카드에도 금액이 없다.

거점에 따라 항목이 달라진다.

| 거점 | 항공편 | 터미널 | 터미널 경유 |
|---|---|---|---|
| 인천공항 · 김포공항 | 표시 | 표시 | 표시 |
| 서울역 · 일산 · 에버랜드 | 숨김 | 숨김 | 숨김 |

`08_요금표.md` §2의 미확정 조합(일산↔홍대, 에버랜드↔홍대)은 숙소 선택지에서 비활성화한다.

### 배차 응답 웹 (대표기사)

가장 단순해야 하는 화면이다. 입력이 세 개뿐이다.

```text
airmail 띠
brand + "배차 요청"
[운행 정보]      읽기 전용 카드. 일시 · 노선 · 주소 · 항공편 · 손님명 · 인원 · 짐 · 옵션 · 특이사항
금액 박스        .bill — 세금포함 총액
[배차 정보]      가능/불가 · 기사 전화번호(.phone-row) · 차량번호
하단 고정 [보내기]
    ↓ 제출 후
완료 stamp 카드
```

만료·중복 제출·취소된 요청은 `.err` 박스로 상태를 명확히 알린다.

### 호스트 운영 화면

`ems-admin.html` 구조를 따른다.

```text
airmail 띠
brand + h1
[오늘·내일]      건별 한 줄. 현재 단계 배지
[확인 필요]      지불 확인 대기 · 배차 불가 · 무응답 · 손님 답장 대기
[상세]           읽기 전용 정보 + 금액 박스(공급가·세금·총액)
                 + 지불 확인 체크 + [배차 요청] 버튼
```

단계 배지는 색으로 구분한다.

| 단계 | 색 |
|---|---|
| 지불 확인 필요 | `--gold` |
| 배차 요청 보냄 / 응답 대기 | `--muted` |
| 배차 완료 | `--leaf` |
| 배차 불가 · 무응답 · 발송 실패 | `--mail-red` |

## 7. 구현 시 지킬 것

- CSS 변수로만 색을 쓴다. 하드코딩한 hex를 컴포넌트에 넣지 않는다.
- 테두리는 1.5px, 카드 radius 14px, 입력 radius 10px, 버튼 radius 12px, pill은 99px로 고정한다.
- 입력 글자 16px 이상.
- `prefers-reduced-motion` 존중 (`ems-admin.html`이 이미 처리하고 있다).
- 세 화면이 같은 스타일시트를 공유한다. 화면별로 CSS를 복제하지 않는다.
- `06_IMPLEMENTATION_READINESS.md` §9에 따라 **UI 프레임워크나 컴포넌트 라이브러리를 추가하지 않는다.** 위 값들을 그대로 쓰면 충분하다.
